日曜日 歌ってみた録音

back number「日曜日」を流しながら、自分の歌声を録音します。

このページは今マイクを使えない開き方になっています。iPhoneで使うには、HTTPS（https://〜）で公開されたページとして開いてください。

1　曲を流す方法

    検索して自動再生するには、YouTubeのAPIキー（無料）が必要です。一度入れればこの端末に保存されます。

    1. Google Cloud の YouTube Data API v3 ページ ↗ を開き「有効にする」
    2. 「認証情報」→「認証情報を作成」→「APIキー」
    3. 表示されたキーをコピーして下に貼り付け

    キーなしで使う場合：YouTubeで検索 ↗ → 動画の「共有」→「コピー」→ ここに戻って

    URLを直接入れる / APIキーの設定
    mp3 / m4a / wav など。iPhoneは「ファイル」アプリ内の音源を選べます

    音源ファイルなら、曲と声を重ねた「ミックス」も作れます。

    2　マイク
    イヤホン・ヘッドホン推奨（スピーカーだと曲が声に混ざります）
    歌詞
    歌詞サイトからコピーして貼り付け。この端末のブラウザ内にだけ保存されます。
      歌い出しに合わせてタップ（PCはスペースキー）すると、その行の時間を記録します。

      行をタップするとその位置へ移動します。

      音量

      iPhoneのYouTube再生では、曲の音量は本体の音量ボタンで調整してください。

      テイク

      まだ録音はありません。

      歌詞はうたネットなどで確認して貼り付けてください。録音はこの端末の中だけで処理され、どこにも送信されません。
