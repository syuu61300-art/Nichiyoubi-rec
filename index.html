01曲をえらぶ

    検索して自動で再生するには、YouTubeのAPIキー（無料）を一度だけ設定します。

    1. YouTube Data API v3 ↗ を開いて「有効にする」
    2. 「認証情報」→「認証情報を作成」→「APIキー」
    3. キーをコピーして下に貼り付け →「保存」

    キーなしで使う：YouTubeで探す ↗ → 動画の「共有」→「コピー」→ 戻って

    URLを直接入れる
    mp3 / m4a / wav（iPhoneは「ファイル」アプリから）

    音源ファイルなら、曲と声を重ねたミックスを保存できます。

      録音したテイク（自分の声）を聞き取らせるのがおすすめです。伴奏が入らないので精度が上がります。

      初回だけモデルをダウンロードし、次回からは端末に保存されたものを使います。音声は端末の外に出ません。

      この方法では、選んだ音声がGroqのサーバーに送信されます。

      キーは console.groq.com/keys ↗ で無料で作れます。この端末にだけ保存されます。
